# rockslop: the English strings. Every assets/lang/<language>.txt translates
# these keys. A key is one line; lines starting with # are notes for
# translators (they apply to the keys below them). {0}, {1}, ... are values
# filled in at run time: keep every one, in any order the language needs.
#
# Style: a hacker-movie flasher. UPPERCASE keys are display labels: keep them
# uppercase in scripts that have case, and short (the space is tight; an
# abbreviation is better than a long word). Lowercase keys are terminal-style
# status lines: terse, lowercase start, no final full stop.
# Technical terms stay as they are: USB, USB-C, SD, microSD, ROM, DFU, ADFU,
# NOR, CPU, CRC32, SHA-256, sha256, MiB, KiB, hex numbers like 0x{0},
# Rockbox, rockslop, YP3, TS17, udev, README, WinUSB, Zadig, sudo, macOS, tar.xz.
